# 내 컴퓨터에서 실행하고 외부에 공유하기 (Windows)

영상은 내 컴퓨터가 만듭니다. 서버 요금이 없고, 화질도 1080p 그대로 쓸 수 있습니다.

| 파일 | 하는 일 | 누가 접속 가능 | 비밀번호 |
|---|---|---|---|
| `start.bat` | 서버 + 화면을 켭니다 | 내 컴퓨터만 | 없음 |
| `share.bat` | 여기에 외부 주소까지 만듭니다 | 주소를 받은 사람 | 필요 |

## 처음 한 번만 할 일

| 프로그램 | 주소 | 비고 |
|---|---|---|
| Python 3.11 이상 | https://www.python.org/downloads/ | 설치 첫 화면에서 **Add python.exe to PATH** 체크 |
| Node.js LTS | https://nodejs.org/ | **LTS** 버튼 |
| ffmpeg | `winget install Gyan.FFmpeg` | 또는 https://www.gyan.dev/ffmpeg/builds/ |
| Git | https://git-scm.com/download/win | 저장소를 받는 데 씁니다 |
| cloudflared | `winget install --id Cloudflare.cloudflared` | `share.bat`을 쓸 때만 |

`start.bat`은 이 중 무엇이 없는지 알려주고 멈춥니다. 직접 설치해 주세요 — 자동으로
설치하지는 않습니다.

## 저장소 받기

```
git clone https://github.com/wegyg/video-ai-studio.git
```

## 매번 실행

- 나만 쓸 때: **`start.bat`** 더블클릭 → 잠시 뒤 브라우저가 열립니다.
- 남에게 보여줄 때: **`share.bat`** 더블클릭 → 비밀번호를 정하면 외부 주소가 표시됩니다.

`share.bat`은 검은 창을 3개 엽니다(서버, 화면, 외부 주소). 이 창들이 열려 있는 동안만
접속됩니다. 끄려면 창을 닫으면 됩니다.

## 비밀번호는 어떻게 동작하나

`share.bat`이 `SHARE_PASSWORD` 환경변수를 정하고, `frontend/middleware.ts`가 그 값이
있을 때만 로그인 창을 띄웁니다. 손님이 주소를 열면 브라우저 기본 팝업이 뜨고,
**아이디는 아무 글자나** 넣으면 됩니다(비워두면 안 됩니다).

미리 정해두고 쓰려면 실행 전에 환경변수를 설정하세요:

```
set SHARE_PASSWORD=mypassword1234
share.bat
```

비밀번호는 영문과 숫자로 만들어 주세요. 배치 파일에서 `!` 같은 특수문자는 값이
깨질 수 있습니다.

`start.bat`은 이 변수를 비우고 시작하므로, 컴퓨터에 전역으로 설정해 두었더라도
로컬 실행에서는 로그인을 묻지 않습니다.

### 무엇이 보호되나

`/api` 를 포함한 모든 경로가 막힙니다. 터널로 공개되는 것은 화면(3000번) 하나뿐이고,
서버(8000번)는 `127.0.0.1`에만 열려 외부에서 직접 닿을 수 없습니다. 화면을 통과하는
모든 요청은 비밀번호 검사를 먼저 지납니다.

실제 터널 주소로 측정한 결과:

| 요청 | 결과 |
|---|---|
| 비밀번호 없이 `/` | 401 |
| 올바른 비밀번호 `/` | 200 |
| 틀린 비밀번호 `/` | 401 |
| 비밀번호 없이 `/api/health` | 401 |

전송 구간은 `https://` 로 암호화됩니다.

## 알아두실 점

- **주소가 매번 바뀝니다.** 계정이 필요 없는 임시 터널이라서 실행할 때마다 새 주소가 나옵니다. 고정 주소가 필요하면 Cloudflare 계정을 만들어 이름 있는 터널을 쓰거나, `docs/deploy.md` 의 서버 배포로 가세요.
- **컴퓨터를 켜 두어야 합니다.** 절전이나 잠자기로 들어가면 공유가 끊깁니다.
- **영상은 내 컴퓨터 성능만큼 빠릅니다.** 서버 무료 플랜과 달리 1080p 기본값을 그대로 씁니다.
- **손님이 영상을 만들면 내 컴퓨터가 일합니다.** 여러 명이 동시에 만들면 느려집니다.
- Pexels 키는 `backend\.env` 에 두세요. 없으면 단색 배경으로 만들어집니다.

## 나중에 서버로 옮길 때

Render / Vercel 설정은 지우지 않고 남겨두었습니다 — `render.yaml`,
`backend/Dockerfile`, `frontend/vercel.json`, 그리고 `docs/deploy.md`. 유료 서버로 갈
때 그대로 쓰면 됩니다. 다만 무료 플랜은 메모리 512MB 한계로 432x768까지만 되니,
1080p로 쓰려면 메모리 2GB 이상인 유료 플랜이 필요합니다.
